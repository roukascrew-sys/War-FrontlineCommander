Dev Tools & Access CodesFrontline Commander — running reference

Everything needed to put a build into a known state for testing, trailer capture and screenshots. Kept in the repo but excluded from the itch.io build by the allowlist in build-itch.sh. Add new tools here as they land so this stays the single place to look.

Why this file is safe to keep in the repo

build-itch.sh copies only the files named in its FILES array (wargame.html, privacy.html, terms.html). Everything else in the repo — including this file — is excluded by default. Verify any time with:

./build-itch.sh && unzip -l dist/frontline-commander-itch.zip

If that listing ever shows more than those three files, stop and fix the build before uploading.

01Access codes

Typed into the access code box in the Debug/Dev panel (title screen → 🐞 Debug/Dev, or the topbar Debug button mid-battle). Matching is case-insensitive and whitespace-trimmed.

CodeNameWhat it does
omegalambda77 MAX ACCOUNT live Puts the account into a full late-game state in one action:
  • Rank 100 (XP zeroed, which is what the cap does naturally)
  • All 9 doctrines unlocked
  • Campaign fully cleared + every time trial passed
  • Secret level unlocked and cleared → grants the Drone Swarm unit and Rods from God strike
  • All rivals defeated, all medals, all three special badges
  • Entire 35-piece crate collection owned
  • All 9 Indoctrination lessons marked cleared
  • Rank-gate bypass on (session-scoped — see §3)
resetall WIPE live Full progress wipe — identical to Settings → Reset Progress. Here so a capture session can start clean without leaving the panel.

These are conveniences, not security

The codes sit in plain text inside wargame.html. Anyone who opens devtools can read them, and anyone who wants to edit their own save can do so without a code at all. That is fine — there is nothing to protect in a single-player client-side game. Don't ever use this pattern to gate something that would matter (paid content, another player's data); that belongs behind a server, and SECURITY.md covers what that needs.

03Session-reset switches

These three are forced off on every page load (SESSION_RESET_KEYS in wargame.html) so nobody — including you — boots into a state that reads as broken:

KeyWhat it is
chaosModeChaos / Meme Mode — every restraint removed
debugUnlockAllRank-gate bypass for modes, doctrines and cosmetics
aiDebugEnemy AI thinking overlay

Everything representing earned progress — rank, XP, unlocks, streaks, crate collection, campaign and time-trial state — is untouched by this and persists normally. After omegalambda77 the account is genuinely Rank 100, so the gate bypass isn't needed on subsequent loads anyway.

Jumping the Gauntlet to any tier

Tier === clears, so you can drop the Adjutant straight onto any rung. This one seeds a tier-5 (full-proficiency, Legendary) opponent that already has you filed as a tank-spamming top-lane player — the fastest way to see every system armed at once:

SAVE.gauntlet={clears:5,losses:0,lifetime:9,deepest:5,
  mem:{fights:6,units:{tank:40,atgm:12,rifle:8},strikes:{barrage:5},
       lanes:[30,4,3],spawners:3,rush:5}};
persist(); launchGauntlet();

Set clears to 9+ for the ASCENDANT tiers (compounding quality/income, no ceiling). G.gauntStrikeT=0 forces its next off-map strike immediately instead of waiting ~30s — useful for capturing the telegraph.

The Adjutant File (analytics)

Debug panel → ◈ The Gauntlet → 🧠 Open Adjutant File. Four tabs:

  • Reasoning — every adjustment as observed → reasoning → action, in plain English. Crucially it also lists decisions it declined to make together with the threshold that stopped them ("no lane crossed 40%, so it is not massing anywhere"), which is almost always the answer when the system looks broken.
  • Analytics — bar charts of what you commit, lane distribution, hardening against the cap, counter-doctrine weighting, and your strike habits.
  • Curve — the effective power climb across every rung as an SVG plot, plus the full rung table (base tier, quality/economy multipliers, opening size, what each arms).
  • Raw — SAVE.gauntlet, the frozen G.gaunt profile, and the live G.gauntRec ledger during a fight.

The same panel has one-tap +1 / −1 tier, seed a tank-spam profile, fight at current tier and purge — enough to demo any adaptation on camera without playing nine matches first.
